# Canal Commons — Project Status

**Last updated:** 28 August 2026

## Current phase

**Commercial Opportunity Validation**

## Current objective

Find and validate a real canal-related transaction for which an independent Canal Commons organisation can create measurable value and receive legitimate commercial compensation.

## What has been tested

| Hypothesis | Current position |
|---|---|
| Canal intelligence / monitoring SaaS | Deprioritised as primary business; CRT already has substantial capability |
| Predictive maintenance | Capability experiment only unless differentiated commercial demand emerges |
| Freight aggregation | Active hypothesis |
| Canalside development / infrastructure interface | Active hypothesis |
| Project finance packaging | Active hypothesis |
| Energy / utility origination | Active hypothesis |
| Tokenisation / crypto | Optional mechanism only; not the business model |

## Current gate

### G2B — Commercial validation

We need three serious real-world transaction candidates and at least one credible path to a paid mandate.

### Pass

- real counterparty identified
- real economic problem identified
- quantified value
- defensible Canal Commons role
- clear payer
- plausible commercial terms
- measurable canal/public/environmental benefit
- realistic route to execution

### Fail / pivot

- no payer
- existing provider already solves it
- Canal Commons adds no material value
- economics do not support a business
- material regulatory or ownership barrier with no practical route around it

## Immediate priorities

1. Validate real development-interface opportunities.
2. Validate a specific freight lane/customer flow.
3. Validate a specific funded project where packaging/origination could create value.
4. Record every rejected opportunity and why it failed.
5. Do not start major software development until a commercial use case is validated.

## Contribution principle

The repository is intended to be understandable to an outsider. Research should be traceable, assumptions labelled, and rejected ideas documented rather than hidden.
