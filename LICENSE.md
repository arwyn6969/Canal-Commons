# Canal Commons licensing

Canal Commons is a mixed-content public project. A single blanket open-source licence is not appropriate for every file because the repository may contain software, documentation, original research, third-party data and material subject to separate licences.

## Default policy

- **Software/code created by Canal Commons:** Apache License 2.0 unless a file or subproject states otherwise.
- **Documentation and original research prose:** Creative Commons Attribution 4.0 International (CC BY 4.0) unless a file or subproject states otherwise.
- **Third-party datasets/material:** the original provider's licence applies. We do not relicense material we do not own.
- **Confidential or commercially restricted material:** should not be published in the public repository.

See `docs/LICENSING-POLICY.md` for the detailed policy.
