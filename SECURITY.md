# Security and sensitive information

Please do **not** publish passwords, API keys, access tokens, private personal information or confidential commercial information in Issues, Discussions, commits or pull requests.

If you discover a security vulnerability in software maintained by Canal Commons, please avoid publicly disclosing exploitable details until the maintainers have had an opportunity to assess it. Contact the repository maintainer privately through GitHub.

For commercial opportunities, submit only non-confidential information to the public repository. Sensitive deal information should be handled through an appropriate private channel.
