## Priority order for the demonstrator

1. Lock 81–83 — because there is a live, documented intervention.
2. Water scarcity — because it is an active operational issue.
3. Ground/embankment screening — because it tests the high-value preventative-maintenance hypothesis.
4. Development/energy opportunity mapping — because it tests the commercial project-origination hypothesis.

## Important caveat

The register does not imply that any listed asset is unsafe. It identifies where Canal Commons should investigate whether additional information could improve decisions. Only competent asset owners/engineers can determine actual condition, safety or required works.
